Privacy Policy — Nurul Quran Pipeline

Last updated: 22 October 2026

Who uses this application

Nurul Quran Pipeline is a personal tool used only by the owner of the Nurul Quran YouTube channel. It is not offered to the public, and no other users sign in to it.

What data is accessed

The application accesses only the owner's own YouTube account, through the YouTube Data API. It uses that access solely to upload videos to the channel and to manage the channel's own videos, thumbnails, metadata and playlists. It does not access any other Google account or any other user's data.

How data is stored

OAuth tokens are stored locally on the owner's personal computer. They are not uploaded to, or stored on, any server. The application has no website backend, no database and no analytics or tracking.

Sharing

No data obtained through Google APIs is sold, transferred or shared with any third party.

How to revoke access

Access can be revoked at any time from your Google Account: go to Google Account → Security → Third-party apps with account access (also available at myaccount.google.com/permissions), select Nurul Quran Pipeline and remove its access. Deleting the locally stored token file also ends the application's access from that computer.

Google API Services User Data Policy

Nurul Quran Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
